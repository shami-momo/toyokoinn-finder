# 토요코인 빈방 알림

원하는 날짜와 호텔을 등록하면 일본 토요코인 공식 사이트의 빈방을 30분마다 확인합니다.

## 시작하기

1. Windows에 Python 3.10 이상을 설치합니다. [Python 다운로드](https://www.python.org/downloads/)
2. 폴더의 **Start.cmd**를 두 번 클릭합니다. 처음 실행할 때는 필요한 파일을 설치하므로 인터넷 연결이 필요합니다.
3. 숙박 조건과 호텔을 선택하고 **감시 대상에 추가**를 누릅니다. 여러 일정을 추가할 수 있습니다.
4. 알림 방식을 설정하고 **감시 시작**을 누릅니다.

## 알림

텔레그램과 이메일을 각각 또는 함께 사용할 수 있습니다. 설정 방법은 화면의 물음표를 눌러 확인하세요. 둘 다 선택하지 않으면 브라우저 알림 권한을 요청합니다.

감시하려면 **프로그램과 컴퓨터가 켜져 있어야 합니다.** 브라우저 알림을 사용한다면 관리 화면도 열어 두세요. 전송에 실패한 알림은 다음 확인 때 다시 시도합니다.

## 검색과 가격

호텔 이름으로 찾거나 장소에서 일정 거리 안의 호텔을 검색할 수 있습니다. 장소는 한국어·일본어·영어로 검색할 수 있지만, 검색되지 않는 경우 다른 표기를 사용해 보세요. 거리는 직선거리입니다.

예약 가능한 플랜 중 회원가가 가장 낮은 플랜과 기타 플랜 수를 표시합니다. 회원 예약이 불가능한 경우 비회원가를 기준으로 표시합니다. 학생 할인은 선택했을 때만 포함됩니다. 플랜별 조건과 실제 예약 가능 여부는 호텔 이름을 눌러 공식 사이트에서 확인하세요.

원화 가격은 하루에 한 번 갱신을 시도하는 환율을 적용한 참고 금액입니다. 인터넷 연결이나 공식 사이트의 상태에 따라 검색 또는 환율 조회가 실패할 수 있습니다.

## 설정 정보

감시 조건과 텔레그램 토큰, 이메일 비밀번호는 이 PC의 `data/data.json`에 저장됩니다. **이 파일은 다른 사람에게 공유하지 마세요.**

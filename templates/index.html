토큰과 비밀번호는 이 PC에 저장됩니다. 기존 값을 유지하려면 비워 두세요

감시 대상 및 결과

상태: 확인 중

  1. 텔레그램에서 BotFather에게 /newbot을 보내고 안내에 따라 봇을 만든 뒤 발급받은 토큰을 입력
  2. 만든 봇과의 대화를 열고 시작
  3. 개인 대화라면 userinfobot에서 확인한 사용자 ID를 채팅 ID로 입력

그룹은 그룹 채팅 ID를 사용하고 봇에 메시지 전송 권한을 부여해 주세요

  1. 보내는 메일 제공업체의 안내에서 SMTP 서버 주소, 포트와 보안 방식 확인
  2. SMTP 계정 이메일과 비밀번호를 입력, 제공업체에 따라 SMTP 사용을 켜거나 별도의 앱 비밀번호를 만들어야 할 수도
  3. 알림을 받을 이메일 주소를 입력하고 이메일을 선택해 감시를 시작, 보내는 주소와 받는 주소가 같아도 가능

일반적인 설정은 STARTTLS와 포트 587, 또는 SSL/TLS와 포트 465, 정확한 값은 메일 제공업체에서 확인 필요
